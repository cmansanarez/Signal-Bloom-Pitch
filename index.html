01

THE QUESTION

Signal Bloom is an open-source audiovisual instrument that combines live coding, generative graphics, AI image generation, and sound-reactive performance.

Signal Bloom treats generation as a performative event.

Signal Bloom explores how improvisation between performer, sound, and machine creates conditions for emergence.

> audio.listen() // live > generate(prompt) // streaming > hydra.modulate(o0) // live > generation := performance // TRUE

What happens when generation becomes the performance?

02

THE SYSTEM

LISTEN

Live audio and performer input enter the system in real time.

GENERATE

Prompts and AI workflows produce imagery through a local ComfyUI pipeline.

TRANSFORM

Hydra and Three.js manipulate that imagery live through code, sound, and performer input.

All image generation occurs locally using open-source tools, custom-trained visual models, and artist-directed workflows. The system is designed as a performance instrument rather than an automated content generator.

HYDRA · THREE.JS · COMFYUI · WEBGL · LOCAL AI

IMPROVISATION the live decisions performers, code, and AI make in the moment.
EMERGENCE the behavior that arises between them — shaped by sound, code, AI, and the audience.

Through these interactions, emergence becomes possible.

03

EMERGENCE

THE CRYSTALLIZATION ARC — NOISE BECOMING FORM.

Signal Bloom exposes the image generation process itself.

NOISE→STRUCTURE→FORM→IMAGE

Intermediate denoising frames are streamed directly into the visual environment. The audience witnesses emergence as it occurs.

The audience experiences the image through its transformation from noise to form.

04

PERFORMANCE WORLD

SEVEN MOVEMENTS, LOOSELY STRUCTURED AROUND ORPHEUS AND EURYDICE. GENERATED WITH THE CUSTOM NOIRMAKSTYLE FLUX LORA.

The full work unfolds across seven movements loosely structured around Orpheus and Eurydice — the myth is never illustrated literally, only felt as a shape for transformation.

A custom-trained visual model gives the performance a recurring language of glitch, recursive architecture, iridescent materials, digital decay, and queer futurism.

Signal Bloom was developed as an audiovisual dialogue with modular synthesist Rayonism (Matt Loewen) — live sound continuously reshapes that world in performance.

  • GLITCH AESTHETICS
  • RECURSIVE ARCHITECTURE
  • IRIDESCENT MATERIALS
  • DIGITAL DECAY
  • QUEER FUTURISM

Each movement reveals a different state of the same computational world.

05

OPEN INSTRUMENT

Built from open-source creative tools — Hydra, p5.js, Three.js, ComfyUI, Stable Diffusion — Signal Bloom is being prepared as an open instrument for other artists to study, modify, and perform with.

The platform provides the framework; each artist develops the language.

The platform is the instrument. The performance emerges through the person playing it.
